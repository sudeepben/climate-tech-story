# Interview Presentation Web Deck

Static GitHub Pages version of the interview presentation.

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static server.

Keyboard controls:

- Right arrow, Page Down, or Space: next slide
- Left arrow or Page Up: previous slide
- N: toggle presenter cues
- F: fullscreen

## GitHub Pages

Publish this repository from the root folder in GitHub Pages settings.
